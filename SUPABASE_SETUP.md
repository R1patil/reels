# ⚡ 3-Minute Supabase Cloud Setup (100% Free)

By default, your app uses a local database (`saas_database.db`). 
To keep user accounts and paid subscriptions permanently in the cloud when you deploy, follow these 4 quick steps:

---

### Step 1: Create a Free Account
1. Go to **[supabase.com](https://supabase.com)** and click **Start your project** (Log in with GitHub or Email).
2. It is **100% free** (includes up to 500 MB database and 50,000 monthly active users).

---

### Step 2: Create a New Project
1. In the Supabase dashboard, click **"New Project"**.
2. Fill in:
   - **Name:** `reelviral-db`
   - **Database Password:** (Pick any password and save it)
   - **Region:** Select the closest region to you (e.g., *East US*, *Central EU*, or *Singapore*).
3. Click **"Create new project"** (it takes about 1-2 minutes to initialize).

---

### Step 3: Create the Users Table (Copy-Paste)
1. In the left sidebar of Supabase, click on the **SQL Editor** icon (`>_`).
2. Click **"New query"**.
3. Copy and paste this exact SQL block:

```sql
CREATE TABLE IF NOT EXISTS users (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    subscription_tier TEXT DEFAULT 'free',
    extractions_used INTEGER DEFAULT 0,
    extractions_limit INTEGER DEFAULT 2,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    last_reset_date TEXT
);

-- Enable public access for your SaaS web app
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon public access" ON users FOR ALL USING (true) WITH CHECK (true);
```

4. Click the green **"Run"** button in the bottom right corner.
5. You will see: `Success. No rows returned`. That's it! Your table is live.

---

### Step 4: Get Your 2 Keys & Connect to the App
1. In the left sidebar, click the **Gear / Settings icon** (Project Settings).
2. Click **"API"**.
3. You will see two values:
   - **Project URL:** Looks like `https://abcdefghijkl.supabase.co`
   - **anon public Key:** A long string starting with `eyJhbG...`
4. Open your app dashboard (`localhost:8502` or `localhost:8501`), expand **"⚡ Cloud Database (Supabase)"** in the sidebar, and paste them!

Your SaaS is now permanently connected to Supabase Cloud! 🎉
